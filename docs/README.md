# Archie Owen Racing — sponsorship site

Plain HTML site, no build step.

## Deploy on Netlify
- **Drag and drop:** go to https://app.netlify.com/drop and drop this whole folder (or the zip).
- **From GitHub:** New site → Import from Git → pick this repo, set **Base directory** to `archie-owen-site`, leave the build command empty, publish directory `.`.
